# Samples

The runnable source and setup instructions remain in the repository. Use this
page to find the sample that matches your scenario.

| Scenario | Sample |
| --- | --- |
| Process blobs using an authenticated Azure Storage client | [Blob trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/blobTrigger) |
| Export telemetry to Azure Monitor through the embedded collector | [Collector to Azure Monitor](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/collectorToAzureMonitor) |
| Process changes from an Azure Cosmos DB container | [Cosmos DB trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/cosmosDBTrigger) |
| Respond to events delivered through Azure Event Grid | [Event Grid trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/eventGridTrigger) |
| Process batches of events from Azure Event Hubs | [Event Hubs trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/eventHubTrigger) |
| Stream HTTP responses from a function | [HTTP streaming](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/httpStreaming) |
| Handle HTTP requests with Go's standard `net/http` types | [HTTP trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/httpTrigger) |
| Add reusable behavior around function invocations | [Middleware](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/middleware) |
| Emit distributed traces with OpenTelemetry | [OpenTelemetry tracing](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/otelTracing) |
| Process messages from Azure Queue Storage | [Queue Storage trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/queueTrigger) |
| Process messages from an Azure Service Bus queue | [Service Bus queue trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/serviceBusQueueTrigger) |
| Process messages from an Azure Service Bus topic subscription | [Service Bus topic trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/serviceBusTopicTrigger) |
| Respond to row changes tracked by Azure SQL | [SQL trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/sqlTrigger) |
| Run a function on a schedule | [Timer trigger](https://github.com/Azure/azure-functions-golang-worker/tree/main/samples/timerTrigger) |
